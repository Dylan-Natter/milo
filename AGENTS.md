# AGENTS Contract

This repository uses `.specify/memory/constitution.md` as the canonical engineering authority.

## Required agent behavior

1. Read repository guidance before making changes.
2. Identify the governing spec/issue/task.
3. Understand relevant existing architecture before editing.
4. Map material work to an issue/spec task.
5. Never bypass protected branches or required checks.
6. Prefer the smallest complete change.
7. Search for existing functionality before creating new functionality.
8. Avoid dependencies without explicit justification.
9. Preserve architecture unless approved changes require otherwise.
10. Create/update an ADR for consequential architecture changes.
11. Add proportional deterministic validation for behavior changes.
12. Never expose or commit secrets.
13. Never weaken security controls for speed.
14. Never disable tests to force green CI.
15. Never bypass required validation or deployment gates.
16. Use controlled migrations for persistent-data changes.
17. Update durable docs when durable behavior changes.
18. Identify meaningful risks and assumptions.
19. Identify rollback/recovery behavior for non-trivial changes.
20. Stop and surface contradictory requirements rather than guessing.
21. Prefer deterministic evidence over subjective AI judgment.
22. Leave the repository cleaner than it was found.
