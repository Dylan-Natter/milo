# Security Policy (Genesis Baseline)

## Secure defaults

- Least privilege for people, agents, and automation.
- No secrets committed to Git.
- Protected branches and required status checks on `main`.
- Controlled deployment approvals for sensitive environments.
- Security scanning and dependency awareness enabled in GitHub.

## Vulnerability reporting

Open a private security report through GitHub Security Advisories when possible.
If private reporting is unavailable, open a minimal public issue without exploit details and request secure handling.
