# Product Genesis Workflow

Product owner input required:
1. Product name
2. Problem
3. Primary users
4. Primary workflow
5. Internal/external/both
6. Data sensitivity
7. Identity/auth needs
8. Initial scale
9. Critical integrations
10. Success outcome
11. Constraints

Progression:
`idea -> clarify -> specification -> non-goals/outcomes -> acceptance criteria -> architecture options -> ADR -> implementation plan -> tasks -> GitHub issues/PRs`

Use Spec Kit commands as the default mechanism for each stage.
