# Specifications

This directory stores product/feature specifications generated and maintained through the Spec Kit workflow.

Suggested flow:
1. Create specification (`/speckit-specify`)
2. Clarify ambiguity when needed (`/speckit-clarify`)
3. Produce implementation plan (`/speckit-plan`)
4. Generate executable tasks (`/speckit-tasks`)
5. Convert tasks into GitHub work items (`/speckit-taskstoissues`)
